# Vansh Bargot — Portfolio Website

A responsive animated portfolio built from the supplied work.

## Publish free
1. Open Netlify Drop: https://app.netlify.com/drop
2. Drag this entire folder (or the ZIP) into the Drop zone.
3. Netlify will give you a live `netlify.app` URL.

The site is static HTML/CSS/JS, so no build step is required.
